# alx-system_engineering-devops

# Shell Variables & Expansions Project

A collection of Bash scripts demonstrating shell variables, expansions, and basic scripting concepts.

## Files

### 0-alias
Creates an alias `ls` that executes `rm *` (dangerous - would delete all files).

### 1-hello_you
Prints "hello" followed by current username using `whoami`.

### 2-path
Adds `/action` directory to the PATH environment variable.

### 3-paths
Counts how many directories are in the PATH variable.

### 4-global_variables
Lists all environment variables using `env`.

### 5-local_variables
Lists all variables and functions using `set`.

### 6-create_local_variable
Creates local variable `BEST="School"`.

### 7-create_global_variable
Creates environment variable `BEST="School"` with `export`.

### 8-true_knowledge
Adds 128 to `$TRUEKNOWLEDGE` using arithmetic expansion.

### 9-divide_and_rule
Divides `$POWER` by `$DIVIDE` using arithmetic expansion.

### 10-love_exponent_breath
Calculates `$BREATH` to the power of `$LOVE`.

### 11-binary_to_decimal
Converts binary number in `$BINARY` to decimal.

### 12-combinations
Generates all two-letter combos (aa-zz) except "oo".

### 13-print_float
Formats `$NUM` to 2 decimal places using `printf`.
