# Shell Variables and Expansions

This project contains Bash scripts demonstrating various shell concepts.

## Scripts

1. **0-alias** - Creates an alias `ls` that executes `rm *`
2. **1-hello_you** - Prints "hello [current_user]"
3. **2-path** - Adds `/action` to the PATH environment variable
4. **3-paths** - Counts directories in PATH
5. **4-global_variables** - Lists environment variables using `env`
6. **5-local_variables** - Lists all variables and functions using `set`
7. **6-create_local_variable** - Creates local variable `BEST="School"`
8. **7-create_global_variable** - Creates environment variable `BEST="School"`
9. **8-true_knowledge** - Adds 128 to `$TRUEKNOWLEDGE`
10. **9-divide_and_rule** - Divides `$POWER` by `$DIVIDE`
11. **10-love_exponent_breath** - Calculates `$BREATH` raised to `$LOVE`
12. **11-binary_to_decimal** - Converts binary in `$BINARY` to decimal
13. **12-combinations** - Generates all two-letter combos except "oo"
14. **13-print_float** - Formats `$NUM` to 2 decimal places
